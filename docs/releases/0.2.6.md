## Release steps (require explicit approval)

1. Bump `VERSION`, `claude/VERSION`, `opencode/VERSION` to `0.2.6`.
2. Rebuild dist for both trees.
3. Update the install target (including `.claude-plugin`).
4. Restart the live MCP process.
5. Probe:
   - `dom_describe` → `DESCRIBED`, `directory`, `db_path`;
   - `dom_plan_status` → `PLAN_STATUS` (B0.3);
   - monitor `/api/health` → `CHAIN_OK`;
   - one prompt → journal + snapshot files appear.
6. Push the branch / open PR **only after approval**.
7. Merge and tag.

## Rollback

- Revert the release commit and reinstall the previous dist; the data schema is unchanged, so no DB rollback is needed.
- Monitor/journal files are runtime data under `.dom-memory/observability` and can be deleted safely.

## Known gaps

- Live MCP still runs 0.2.4 until step 4.
- No session binding, no `read_receipts`, no gate; 0.3.0.
- Native OpenCode Panel is 0.3.1; the web panel is the 0.2.6 deliverable.
- `hook_order` is `unknown`; a plugin registered after DOM is not in the snapshot.
- `memory_runtime_snapshot.json` is generated and machine-specific; do not treat it as a portable artifact.
